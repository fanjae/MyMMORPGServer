# 기본 공격·하단 HP/MP — 2026-10-12

## 구현

- 3D 플레이어는 J·왼쪽 Ctrl·하단 ATTACK 버튼으로 기본 공격한다. 검 휘두르기는 입력 즉시 표시하고, 몬스터 피해는 서버가 확정한다. 누른 채 반복되는 OS 키 이벤트는 새 공격으로 취급하지 않는다.
- 서버는 인증된 캐릭터의 HP 조회 완료·생존 여부, 현재 Map/generation, 최신 이동 actionSequence, 증가하는 공격 sequence, 500ms 간격을 확인한다. Map 이동으로 재사용 대기 시간을 초기화하지 않는다.
- 검증된 XYZ·방향으로 전방 3m, 높이 차이 1.5m 이내의 가장 가까운 살아 있는 몬스터 한 마리를 선택한다. 방향 내적 0.35 이상, 지형 박스를 통과하지 않는 공격만 적중한다. 공격 요청에 피해량·대상·좌표를 받지 않는다.
- 적중 피해는 20, 몬스터 최대 HP는 60이다. 사망하면 표시와 순찰을 멈추고 5초 후 HP 60으로 재생성한다. 같은 필드에 공격자·결과·HP·변경 번호를 공유하며 수신자별 generation을 적용한다. 늦은 목록이 HP를 되돌리지 않도록 revision을 비교한다.
- 기본 공격은 MP를 소모하지 않는다. 몬스터의 플레이어 공격, 드롭, 장비 능력치는 이번 범위에 포함하지 않는다. 몬스터 HP는 Map 메모리 상태로 유지하며 서버를 재시작하면 초기화된다.
- 하단 HP·MP 숫자/게이지는 씬의 인벤토리 Canvas 아래에 저장했다. 같은 서버 인벤토리 snapshot을 사용하며 물약 성공 응답과 함께 갱신한다. 로딩 중에는 `--/--`을 표시한다. 인벤토리를 닫아도 유지하고 필드를 나가면 숨긴다.

## 송신·표시 비용

공격을 기존 이동 checkpoint 묶음 뒤에 전송해 서버가 확인한 위치를 사용한다. 이동 송신 상한 5회/초를 유지한다. 공격 sequence는 Map 변경·입력 차단에서 유지하고 대기 공격만 취소한다. HP/MP 숫자·게이지와 몬스터 이름·생존 오브젝트는 값이 바뀔 때만 갱신한다. 몬스터 목록의 기존 tick별 공통 패킷 재사용을 유지한다.

3D game protocol은 **9**다. 몬스터 레코드가 31바이트로 늘어 최대 128마리의 전체 패킷은 3,994바이트이고 기존 4,096바이트 한도에 들어간다. 공격 요청 payload 28바이트, 결과 45바이트다. 서버·3D 클라이언트 실행 파일을 함께 갱신한다. Login 2·2D 6과 DB 스키마는 유지한다.
